# 功能指南

GodotX 将对话 Agent、视觉生成和可复用技能拆分为三个独立工作区。它们共享 Provider 配置和项目边界，但承担不同职责。

## GodotX 工作区

### 流式对话

- 流式回复和推理摘要。
- Markdown 标题、列表、引用、代码块、链接和受限表格。
- 用户、助手、思考和工具记录使用不同视觉层级。
- 工具日志可展开查看参数、输出和文件修改详情。
- 只有用户仍位于底部时才自动跟随滚动。

### 会话管理

- 新建、切换、重命名和删除会话。
- 按项目隔离的本地持久化。
- 编辑器重启后恢复完成的时间线和最后选择。
- 长历史分页查看。
- Provider 无关的上下文压缩，保持工具调用与结果成对。

会话快照不保存 Provider 配置或 API Key。崩溃时仍处于运行状态的任务会恢复为“已中断”，不会重放审批或编辑器请求。

### 项目语义索引

增量索引覆盖：

- `.gd`
- `.gdshader`
- `.tscn`
- `.tres`
- `project.godot`

索引提供符号搜索、引用查找和依赖图。对相关本地任务，Runtime 会在第一次模型请求前准备一个有界上下文包；普通问候和通用问题会跳过检索。

### Godot API 查询

`godot_api_query` 读取当前编辑器的 `ClassDB` 和全局脚本类注册表，可以查询：

- 继承关系。
- 属性与类型。
- 方法与参数。
- 信号。
- 枚举和常量。

这使模型使用已安装 Godot 版本的真实 API，而不是依赖训练数据记忆。

### 文件编辑

Runtime 工具包括文件列表、读取、文本搜索、事务补丁和受控命令执行。文件修改流程：

```text
准备内存变更
  -> 展示 unified diff
  -> 请求批准
  -> 复核基础哈希
  -> 原子写入或回滚
```

模型的文字声明不被视为修改成功，只有工具返回的应用结果才会进入时间线。

### 实时场景读取

EditorBridge 可以读取未保存的编辑器状态：

- 场景树。
- 当前选择。
- 节点属性。
- 项目资源元数据。

每个任务只可访问提交时已经打开的场景。场景关闭、根实例变化或修订不匹配时，操作会拒绝执行。

### 实时场景编辑

结构化操作包括：

- 新增节点。
- 修改属性。
- 重命名。
- 删除。
- 复制。
- 重设父节点。
- 实例化 PackedScene。

每个场景的一批操作会成为一个独立 Undo 动作，并保持未保存状态。多场景任务对每个场景分别创建 Undo 记录。

### 游戏调试

GodotX 通过当前编辑器提供：

- 启动项目主场景、当前场景或指定场景。
- 查询 debugger 生命周期、结构化错误和有界输出。
- 停止由当前 GodotX 实例启动的精确 `run_id`。

手动使用编辑器运行的游戏不会被接管或停止。

### 运行时模拟自动化

该功能默认关闭，需在设置中按项目启用。支持：

- 等待指定帧数。
- 点击当前场景中的 Control。
- 发送 InputMap 动作。
- 断言节点属性等于或包含预期值。

`game_test` 是推荐的组合工具，它在本地完成启动、Probe 就绪、执行、结果收集和精确清理，减少模型轮询与 Token 消耗。自动化设置和审批模式彼此独立。

### 公共网页工具

`web_search` 和 `web_open` 用于检索当前公开信息。搜索优先使用公共 MCP，并在服务不可用或免费额度耗尽时回退到多个搜索来源。

网页内容始终作为不可信外部输入处理。工具拒绝私有地址、不安全重定向、凭据 URL、非文本响应和过大正文。

## ImageX 工作区

### 单张图片

直接根据提示生成一张图片，可选择模型、尺寸、质量、背景和格式。自定义最终尺寸与 Provider 请求尺寸分离，Runtime 会在本地生成精确尺寸的 PNG。

### AI UI 套件

工作流包括：

1. 冻结当前 Control 树和可选 2D 视口。
2. 由当前聊天模型生成严格资产计划。
3. 顺序生成最多四个视觉一致的素材。
4. 可选执行一次视觉复核。

为了控制成本，复核失败不会自动触发无限重生成。

### 精灵换皮

- 输入 16 到 2048 像素的项目纹理。
- 保持原画布尺寸。
- 输出新的透明 PNG。
- 不覆盖源文件。

### 图集变体

- 输入固定网格图集。
- 行列数必须能整除原图尺寸。
- 最多 256 帧。
- 保持原始网格和画布几何。

### 透明背景

Runtime 优先请求原生透明图片。如果 Provider 明确拒绝透明背景或返回不透明图片，会进行一次绿色背景重试，并只移除与画布边缘连通的绿色区域，同时抑制绿色溢色。

### 视觉输入与批注

附件存入 GodotX 用户数据目录，WebSocket 只传递附件 ID 和元数据，不传 Base64。每轮最多四张图片。图片可携带箭头、圆形和矩形批注。

## SkillX 工作区

技能是有界的 `SKILL.md` 指令文档：

- 内置技能随插件发布。
- 个人技能保存在 Godot 用户数据目录。
- 项目技能保存在 `.godetx/skills/<name>/SKILL.md`，可以提交到版本控制。

同名技能按“项目 > 个人 > 内置”覆盖。技能可通过 `$skill-name` 显式选择，也可根据触发短语和描述本地匹配。一次任务最多加载三个技能。

技能只能提示当前任务策略已经允许的工具，不能扩展工作区、审批、命令、场景租约或自动化权限。

## 本地化

插件提供英文和简体中文。它读取主机操作系统语言，并对不支持的语言回退到英文。这个选择只影响插件，不修改项目自身的国际化设置。
